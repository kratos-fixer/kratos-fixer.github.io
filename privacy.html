Privacy policy

kratos-agents is a private tool with a single user: its owner.

What it accesses

With the owner's consent through Google sign-in, it reads and writes the owner's own Google Sheets, Docs and Drive files.

What it does with the data

The data is used only to perform the tasks the owner requests. It is not sold, shared with third parties, or used for advertising. Google user data is handled in accordance with the Google API Services User Data Policy, including the Limited Use requirements.

Storage and removal

Access tokens are stored only on the owner's own computer. Access can be revoked at any time at myaccount.google.com/permissions.
